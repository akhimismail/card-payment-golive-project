# Debit Card BIN Migration & Go-Live — TPM Project Artifacts

## About This Project
This is a self-directed practice project simulating the deliverables a Technical Project Manager produces when leading a card payment platform migration — from planning through go-live and post-launch incident response.

It's modeled on real industry practice for debit card BIN migrations (issuer → processor → card scheme workflows), built to demonstrate practical fluency in payments/fintech delivery: stakeholder management, risk management, cutover planning, and incident management.

**This is a practice/portfolio project, not a real client engagement.** Scenario, numbers, and organizations are illustrative.

## Scenario
A retail bank migrates ~450,000 active debit cards from a legacy processor to a new processing platform — requiring Visa re-certification, a zero-downtime cutover, and coordination across engineering, QA, infrastructure, and customer support.

## Why This Project
Written to build and demonstrate working knowledge of card payment delivery concepts (BIN, issuer/acquirer, authorization vs. settlement, card scheme certification, chargebacks, PCI-DSS, DR readiness) applied to the same kind of project a Technical Project Manager would run in a payments/banking technology team.
